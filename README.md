# CSCE 679 - Data Visualization Assignment 1

## Hong Kong Temperature Heatmap

This project implements the Level 1 and Level 2 visualizations for CSCE 679 Assignment 1 using the instructor-provided daily temperature dataset.

## Dataset

The project uses the `temperature_daily.csv` dataset provided by the instructor.

## Visualizations

- Level 1: Monthly temperature heatmap.
- Level 2: Daily temperature details and mini line charts.

## Technologies

- HTML
- CSS
- JavaScript
- D3.js
