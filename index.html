Hong Kong Temperature Heatmap

Daily temperature records for Hong Kong (temperature_daily.csv)

Level 1: Monthly Temperature Heatmap

Each cell is one month of one year. Use the buttons to switch between the highest and lowest daily temperature recorded in each month. Hover over a cell for details.

Level 2: Daily Temperature Details

The latest 10 years on the same year-month grid. Each cell shows how the daily maximum and minimum temperatures changed during that month. Hover over a cell to read the value for a specific day. The cell background shows that month's maximum temperature (see the color legend on the right).

CSCE 679 Data Visualization, Assignment 1. Built with HTML, CSS, JavaScript and D3.js.
